# Changelog

## 0.1.0 — 2026-10-17

- Static embedded GLB 2.0 and triangle OBJ inspection with bounded parsing.
- Attribute-aware meshoptimizer LOD preparation, stream compaction, material boundaries and embedded PNG/JPEG preservation.
- Explicit scale and bottom-center conversion, complete binary geometry previews, JSON/HTML reports, SHA256 provenance and ZIP handoff.
- Local browser workspace and shared CLI with bounded subprocess jobs, request token and origin/Host checks.
- Original 131,072-triangle procedural demo, regression tests and Unity Editor LODGroup helper.

Known scope: static geometry only; no texture baking, external resources, animation, collider generation or device-performance promises. Unity execution and hosted CI results have not been verified locally.
